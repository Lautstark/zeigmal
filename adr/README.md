# Decisions

Every file here exists because the decision it records looks like an oversight
from the outside. Four digits, a sentence for a title, never renumbered; a
superseded decision keeps its number and gains a status line. The same shape as
in `Lautstark/bildhaft` and `Lautstark/vorlaut-diy-talker`; the sequence is this
repository's own.
